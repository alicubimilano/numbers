# Numbers · Alicubi

Repository dedicato ai giochi e agli strumenti matematici digitali sviluppati per il lavoro didattico di Alicubi.

## Progetti

### Pari o Dispari? — V6
Primo gioco disponibile. Lavora sul riconoscimento visivo delle quantità, sul concetto di coppia/intruso e sulla distinzione tra numeri pari e dispari.

Sorgenti: `pari-dispari/`

### Sposta lo zero! — V1
Gioco autonomo sul valore posizionale, sull’ordinamento delle cifre e sull’inserimento o sostituzione dello zero. Prototipo da testare con Alice.

Sorgenti: `sposta-lo-zero/`

Gioco: https://alicubimilano.github.io/numbers/sposta-lo-zero/

Checkpoint: `sposta-lo-zero/CHECKPOINT_V1.md`
